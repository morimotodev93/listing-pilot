# 0007: 商品別カスタム値と原子的保存・安全な削除

- 日付：2026-11-12（日本時間）
- 状態：採用・Phase 4.2実装

## 保存と読み取り

スキーマVersion 3と既存0001〜0003を維持する。値は既存product_attribute_valuesにTEXTで保存し、
未設定は行なし。IDで定義に関連付け、単位は定義を参照する。Textは前後trim後2,000 Unicode文字以内、
制御文字・改行はtrim前に拒否する。Numberは `^-?[0-9]{1,15}(\.[0-9]{1,6})?$` を文字列として検証し、
浮動小数点変換・丸めを行わない。0、負数、先頭ゼロと小数末尾ゼロを保持する。

`get_product_edit_snapshot({ id })` は商品・全定義・全値を同じ読取トランザクションで返す。
値はattribute_id昇順。UIは非表示定義を入力対象から除くが、取得値には非表示の値も含む。
新規フォームは共通定義を取得する。取得失敗は空値とみなさず保存を禁止する。

既存create_product/update_productに任意のトップレベル引数 `attributeValues` を追加する。
商品inputの既存構造、返却Product、update_productのexpectedUpdatedAtを維持する。

- 省略／null：値に触れない旧呼び出し。
- `{ editableDefinitions: [], values: [] }`：明示的な編集対象なし。既存値は変更しない。
- editableDefinitions：attributeIdとexpectedUpdatedAtを持つ、今回の編集対象。
- values：attributeIdとvalue。編集対象の空値／値省略はその項目だけ未設定へ戻す。
- 編集対象外の値、重複ID、不在ID、不正値は拒否する。編集対象にない既存値は保持する。

商品保存と対象値のUPSERT／個別DELETEは単一IMMEDIATEトランザクション内で行う。
途中失敗は商品本体・更新日時・全対象値をロールバックする。商品更新日時は値だけの変更でも進める。
定義は保存直前に現在の更新日時と非表示状態を確認し、変更・非表示化との競合はstale_dataとする。
非表示定義に値を設定・変更・削除する通常APIは設けない。名前変更・復元で元の値を再利用する。
全値DELETE後の再INSERTは行わない。画像操作では商品更新日時を変えない。

Reactは同期refで二重送信を防止し、競合時は入力を保持して保存を停止する。自動再送しない。
保存成功後の一覧取得失敗は保存成功の通知と取得エラーを併記し、保存を再実行しない。

## 商品削除

ADR 0005のpermit、Mutex解放中の全ファイル事前検査、IMMEDIATEでの再照合、COMMIT後の隔離を維持する。
削除プレビューの読取トランザクションに全カスタム値を追加し、`attribute_values` を返す。
確認UIは非表示項目を含む登録値件数と、商品に属する値が削除されることを表示する。
確定inputには `expectedAttributeValues` の完全なスナップショットを必須とする。

事前照合とIMMEDIATE内の両方で全値を比較し、値の追加・変更・削除をstale_dataとして拒否する。
値比較には定義名・定義更新日時を含めず、名前変更だけで商品削除を失敗させない。
対象商品IDに限定して値をDELETEし、実削除件数を照合してから画像メタデータと商品を削除する。
共通定義と他商品の値は削除しない。残存参照検査にカスタム値の参照も含める。

COMMITエラー後はautocommitと商品・全画像ID／パス・カスタム値の参照を同一スナップショットで再照会する。
全参照なしと確定した場合だけ画像隔離へ進む。参照が残る完全ロールバックはDBエラー、
一部残存・値の変化・状態照会不能はproduct_deletion_unknownとし、管理画像を保持する。
隔離の非置換・欠落許容・保留集計・起動時回収は既存仕様を維持する。

依存、通常保存先、識別子、CSP、Capabilities、Asset Protocolの範囲は変更しない。
検証結果と未検証事項は [検証記録](../verification.md) を参照。
